# Climate Change & Environmental Impact Dashboard

**Interactive Data Visualization Dashboard using Power BI**

---

## Project Description

The **Climate Change & Environmental Impact Dashboard** is an interactive data visualization project developed using **Microsoft Power BI** to analyze global environmental trends and climate change patterns.

The dashboard presents insights on important climate indicators such as **CO₂ emissions, greenhouse gas levels, temperature changes, sea level rise, renewable energy usage, fossil fuel consumption, and extreme climate events**.

The dataset includes multiple countries such as USA, China, Germany, Brazil, Mexico, Japan, UK, Saudi Arabia, South Africa, Argentina, Spain, and Australia across multiple years.

The project transforms raw environmental data into meaningful visual insights using charts, KPIs, maps, and interactive filters. The dashboard allows users to explore trends over time and compare countries based on environmental performance.

Different pages focus on specific aspects of climate analysis such as emissions, sea level rise, energy usage, and extreme climate events. Interactive slicers allow users to dynamically filter the data and understand relationships between variables.

The project demonstrates how data analytics can support decision-making in environmental sustainability and climate risk assessment.

This dashboard is designed for **students, researchers, analysts, and policymakers** to understand climate patterns through clear and interactive visualizations.
